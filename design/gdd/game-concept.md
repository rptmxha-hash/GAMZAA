## Elevator Pitch

> 명상적인 손끝 터치로 4일 동안 감자 한 알을 돌보는 파스텔 수채 힐링 방치형 모바일 게임 —
> 창문을 밀어 환기하고 난로를 눌러 온기를 주며, 시든 감자도 시간을 되돌려 되살릴 수 있어
> 바쁜 하루 사이사이 죄책감 없는 위안을 준다.

**10초 테스트**: "날씨에 맞춰 손으로 감자를 돌보고, 다 자라면 옷 입혀 마을로 보내는 힐링 게임." ✅

## Core Fantasy

바쁜 일상 속에서 **내가 돌보는 작은 생명이 무사히 자라나는 것을 지켜보는 따뜻한 안도감과 애착.**

플레이어는 화려한 성취나 정복이 아니라, "내 손끝으로 이 작은 감자를 지켜냈다"는 조용한 보람을 얻는다.
날씨가 험해지면 손으로 창문을 밀고 난로를 지펴 감자를 돌보고, 감자는 ASMR 반응으로 화답한다.
여기서만 가능한 것: **어떤 실수도 되돌릴 수 있는, 벌주지 않는 케어.** 방치해서 시들어도 시간을 되돌려
다시 안심할 수 있기에, 이 게임은 위안을 주되 상실의 공포를 팔지 않는다.

---

## Unique Hook

**"그림책 창문" 아날로그 오감 터치** — 방치형 케어 게임이지만, 버튼을 탭하는 게 아니라
손가락으로 유리창을 **밀어서** 환기하고, 난로를 **지긋이 눌러** 온기를 피운다. 각 조작에는
빗소리·장작 타는 소리 같은 자연 ASMR 반응이 즉각 붙는다.

*"like 다마고치, AND ALSO 손으로 어루만지는 아날로그 촉감 + ASMR 반응 + 죄책감 없는 시간 되돌리기."*

이 훅은 겉멋(aesthetic gimmick)이 아니라 게임플레이의 핵심이다 — 조작 자체가 위안(Submission)이라는
1순위 미학을 직접 전달하는 수단이기 때문이다.

## Player Experience Analysis (MDA Framework)

### Target Aesthetics (What the player FEELS)

| Aesthetic | Priority | How We Deliver It |
| ---- | ---- | ---- |
| **Submission** (relaxation) | **1** | 낮은 스트레스 루프, 짧은 세션 완결, 되돌림 안전망, 잔잔한 페이스 |
| **Sensation** (sensory pleasure) | **2** | 파스텔 수채 비주얼, ASMR 오디오, 아날로그 터치 촉감 피드백 |
| **Fantasy** (make-believe) | **3** | 작은 생명을 돌보는 양육자 판타지, 감자의 표정과 반응 |
| **Expression** (self-expression) | **4** | 코스튬 30종, 감자에 이름 붙이기, 감자 마을 꾸미기 |
| **Discovery** (exploration) | 5 | 코스튬 컬렉션, 감자 품종/표정 변화 (소규모) |
| **Narrative** (drama) | N/A | 명시적 스토리 아크 없음 — 정서적 톤만 존재 |
| **Challenge** (mastery) | 최소 | 방치 시 "적당한 긴장"만 — 벌주지 않음 |
| **Fellowship** (social) | N/A | 안티필러 — 경쟁·소셜 배제 |

### Key Dynamics (Emergent player behaviors)

- 플레이어가 **하루 확인 리듬**을 형성한다 (습관적 짧은 세션).
- 플레이어가 **개별 감자에 애착**을 형성한다 (이름·표정·수확 카드를 통해 기억으로 남김).
- 플레이어가 **오프라인 안전 최적화** 행동을 한다 (취침·업무 전 8시간 온실막을 미리 설치).
- 플레이어가 **수집·개인화**에 몰입한다 (코스튬, 마을 채우기).

### Core Mechanics (Systems we build)

1. **아날로그 터치 케어** — 창문 드래그(습도), 난로 꾹 누르기(온도), 물뿌리개(수분).
2. **날씨 기반 상태 관리** — 24h 백그라운드 날씨 체인저 + 습도/온도/수분 스탯.
3. **방치형 생애주기 진행** — 4일(발아→성장→비대→수확) 자동 성장.
4. **회복 & 보호** — 시듦 → 광고 시청 시간 되돌리기 → 8시간 온실막 보호.
5. **수집 & 표현** — 코스튬, 감자 이름 붙이기, 감자 마을.

## Player Motivation Profile

### Primary Psychological Needs Served

| Need | How This Game Satisfies It | Strength |
| ---- | ---- | ---- |
| **Autonomy** | 언제 들어올지, 어떻게 꾸미고 이름 붙일지 자유. 강제 경로 없음. | Supporting |
| **Competence** | 날씨→대처 매핑을 익히고 감자를 최상 상태로 유지하는 잔잔한 숙련. | Supporting |
| **Relatedness** | **감자에 대한 양육적 애착** — 이 게임의 정서 엔진. (단, 타 플레이어와의 관계는 배제) | **Core** |

### Player Type Appeal (Bartle Taxonomy)

- [x] **Achievers** — 코스튬 컬렉션, 4일 사이클 완주, 마을 채우기 (보조 동기)
- [x] **Explorers** — 날씨 반응·코스튬 변화 발견 (소규모)
- [ ] **Socializers** — 설계상 배제 (싱글플레이, 경쟁 없음). 향후 '마을 방문' 같은 부드러운 공유는 검토 가능하나 코어 아님.
- [ ] **Killers/Competitors** — 완전 배제 (안티필러: 경쟁/랭킹 없음)

> **주력 아키타입**: Bartle 4분면에 깔끔히 안 들어오는 **"돌보는 사람(Caretaker/양육형)"**.
> Quantic Foundry 기준 자극(Excitement) 낮음 · 평온(Calm)·판타지(Fantasy) 높음 성향.

### Flow State Design

- **온보딩 커브**: 첫 감자를 심고 2분 내에 물 주기·창문·난로를 가이드로 체험.
- **난이도 스케일링**: 날씨 이벤트가 약간 잦아지고 다양해지되 결코 가혹하지 않음. 안전망 상시 제공.
- **피드백 명료성**: 감자의 표정·ASMR 반응이 상태를 즉각 신호. 대처 전/후가 뚜렷.
- **실패로부터의 회복**: 즉각적 — 광고 되돌림으로 복원, 영구 상실(퍼머데스) 없음.

## Core Loop

### Moment-to-Moment (30초)
날씨를 보고 감자 상태를 손으로 매만진다 — 창문을 밀어 환기 / 난로를 지긋이 눌러 온기 / 물뿌리개로 물 주기.
각 조작에 감자의 ASMR 반응(빗소리·장작 소리·하트 등)이 즉각 붙는다. **조작 자체가 위안**이라
어떤 진행 없이도 이 순간이 기분 좋아야 한다.

### Short-Term (5~15분)
현재 날씨 이벤트(맑음·폭우/안개·한파/폭설·폭염) 1건을 해결하고 감자를 최상의 수분/온습도 상태로 되돌린다.

### Session-Level (방치형 특성상 짧고 잦음)
하루 여러 번 짧게 들어와 상태 확인 → 대처 → 안심하고 나가기. **자연 정지점**은
"8시간 철통 온실막" 설치 — 취침/업무 중에도 안심 방치 가능.

### Long-Term Progression
4일 생애주기 반복: 발아 → 성장 → 비대 → 수확 → 코스튬 입혀 이름 붙이고 마을로 보내기 → 새 감자 시작.
마을에 나만의 감자 컬렉션과 평생 간직하는 수확 카드가 쌓여간다.

### Retention Hooks
- **Curiosity**: 다음 코스튬, 새 감자가 어떤 표정일지, 아직 안 본 날씨 반응.
- **Investment**: 정서가 누적된 내 감자 — 지켜주고 싶은 마음. 쌓아온 마을 컬렉션.
- **Social**: 없음 (설계상 배제).
- **Mastery**: 날씨 대처를 잘해 감자를 완벽하게 키워내는 잔잔한 숙련.

## Game Pillars

### Pillar 1: 손끝의 위안 (Comfort at the Fingertips)
아날로그 터치와 ASMR 반응이 게임의 심장. 모든 상호작용은 눈보다 손과 귀로 먼저 느껴져야 한다.

*Design test*: 새 기능이 촉감/소리 보상을 못 주면 → 단순 UI 버튼이 아니라 아날로그 조작으로 재설계하거나 뺀다.

### Pillar 2: 지켜주고 싶은 마음 (Something Worth Protecting)
플레이어가 감자에 정서적으로 애착을 갖게 만든다. 애착이 있어야 부활·보호가 '과금 압박'이 아니라 '내 감자를 지키는 선택'이 된다.

*Design test*: 감자를 익명 자원처럼 다루는 설계 vs 이름·표정·기억을 부여하는 설계가 충돌 → 후자를 택한다.

### Pillar 3: 벌주지 않는 힐링 (Healing That Never Punishes)
방치에 적당한 긴장은 주되, 되돌림 안전망으로 어떤 실수도 회복 가능하게 한다. 죄책감·상실의 공포를 팔지 않는다.

*Design test*: "방치하면 감자를 영구히 잃음" vs "광고/시간으로 항상 되돌림"이 충돌 → 항상 되돌릴 수 있는 쪽. 공포로 과금을 유도하지 않는다.

### Pillar 4: 짧게, 자주, 부담 없이 (Bite-Sized, Never Demanding)
한 번에 30초~2분이면 할 일을 끝내고 안심하고 나갈 수 있다. 게임이 플레이어의 시간을 인질로 잡지 않는다.

*Design test*: 접속 강제·긴 튜토리얼·놓치면 손해인 실시간 이벤트 vs 짧은 세션 완결이 충돌 → 짧은 세션.

### Anti-Pillars (What This Game Is NOT)

- **NOT 경쟁/랭킹**: PvP·리더보드는 위안(Submission) 미학을 정면으로 해친다.
- **NOT 공포 마케팅 과금**: "지금 안 하면 감자가 죽는다"는 상실 공포로 과금을 강요하지 않는다 — Pillar 3 위반.
- **NOT 복잡한 시뮬레이션**: 수치·자원 관리를 복잡하게 쌓지 않는다. 인지 부하는 힐링을 깨고 Pillar 4를 위반한다.
- **NOT 하드코어 실시간 압박**: 놓치면 큰 손해인 실시간 한정 이벤트로 접속을 강제하지 않는다.

## Visual Identity Anchor

향후 아트 바이블의 씨앗. `/brainstorm`에서 확정된 시각 방향.

- **선택된 방향**: **"수채 그림책 (Watercolor Storybook)"**
- **한 줄 시각 규칙**: *모든 화면은 종이 위에 번지는 파스텔 수채 한 장면처럼 보여야 한다 — 선명한 벡터가 아니라 부드러운 손그림.*
- **지지 원칙**:
  1. **번짐과 종이 질감** — 딱 떨어지는 디지털 엣지 대신 물감의 번짐·종이결을 살린다. *테스트*: 에셋이 벡터처럼 깔끔하고 차가우면 → 수채 텍스처를 입히거나 반려.
  2. **부드러운 손그림 윤곽선** — 두껍고 균일한 라인이 아니라 연필/붓의 강약이 있는 선. *테스트*: 라인이 기계적으로 균일하면 → 손그림 톤으로 재작업.
  3. **정적인 포근함** — 화려한 이펙트보다 그림책 한 장을 넘기는 듯한 잔잔함. *테스트*: 이펙트가 시선을 강하게 낚아채면 → Submission 미학에 맞게 순화.
- **색 철학**: 채도 낮은 파스텔 팔레트. 온기(난로 주황), 촉촉함(비 하늘색) 등 날씨 정서를 색으로 전달. 자극적 원색·고대비 회피.

## Risks and Open Questions

### Design Risks
- 방치형의 '재미'가 손맛·애착에 크게 의존 — 프로토타입 없이는 아날로그 터치가 실제로 위안이 되는지 불확실.
- 광고 부활이 힐링 톤과 충돌할 위험 (Pillar 3 ↔ 수익) — 균형 튜닝 난이도 높음.
- 애착 형성이 약하면 부활 광고 클릭률(기대 수익의 50%) 붕괴.

### Technical Risks
- 백그라운드 24h 타이머 + 시계 조작·타임존 변경 악용 방지 — 솔로 첫 게임에게 까다로운 영역.
- 광고 SDK 보상 무결성 및 치팅 방지.
- 오프라인 진행 계산의 정확성·엣지케이스(장기 미접속, 기기 변경).

### Market Risks
- 힐링 방치형 장르 포화 — 차별점(아날로그 손맛 + 감자 IP의 신선함)에 성패가 달림.
- 광고 온리 수익 모델의 ARPU 한계.

### Scope Risks
- **솔로 × 첫 게임 × 라이브 요소(가챠·코스튬 30·마을·이벤트) = 최대 리스크.** 완주 실패 가능성 높음.
  → MVP를 극단적으로 좁혀 코어 가설만 먼저 검증해야 함.
- 수채 손그림 코스튬 30종 + 감자 표정 다수 = 아트 물량이 솔로에게 과중.

### Open Questions
- 아날로그 터치(손맛)가 실제로 위안을 주는가? → **`/prototype`으로 검증** (최우선).
- 방치 긴장감의 적정 강도는? → 플레이테스트로 튜닝.
- 감자 애착이 광고 클릭으로 이어지는가? → 소프트런칭 FGT로 검증.

## MVP Definition

**Core hypothesis**: "명상적 아날로그 터치로 감자를 돌보는 4일 루프가, 짧은 세션으로 위안을 주고
다시 들어오고 싶게 만드는가?"

**Required for MVP**:
1. 감자 1마리 + 4일 생애주기(발아→성장→비대→수확) 자동 성장.
2. 날씨 3종(맑음/비·안개/한파) + 대응 조작(물뿌리개/창문 드래그/난로 누르기).
3. 감자의 ASMR 반응 & 표정(상태 신호).
4. 시듦 → 광고 되돌리기 → 8시간 온실막 보호.
5. 수확 → 이름 붙이기 → 간직 카드 1장.
6. 수채 아트(플레이스홀더 허용) + 코어 ASMR 사운드.

**Explicitly NOT in MVP** (defer):
- 가챠(스티커 상자), 코스튬 30종(1~2종만), 감자 마을 라이프·상호작용.
- 비(Rain) 부스터, 라이브옵스 이벤트, 클라우드 세이브.
- 폭염/폭설 등 확장 날씨, 다수 코스튬 표정 변형.

### Scope Tiers (if budget/time shrinks)

| Tier | Content | Features | Timeline (솔로) |
| ---- | ---- | ---- | ---- |
| **MVP** | 감자 1·날씨 3·코스튬 1~2 | 코어 터치 케어 루프 + 되돌림/온실막 + 수확 카드 | ~2–3개월 |
| **Vertical Slice** | 날씨 4종 완비·코스튬 5·마을 뷰 | 코어 + ASMR 사운드 패스 + 광고 SDK 연동 | +3–4개월 |
| **Alpha** | 코스튬 15–20·가챠·비 부스터 | 마을 상호작용 + 세이브 + 전 부스터 (러프) | +4–6개월 |
| **Full Vision** | 코스튬 30·마을 라이프 | 라이브옵스 이벤트 + 폴리시 + 스토어 소프트런칭 | 총 12–24개월 |
